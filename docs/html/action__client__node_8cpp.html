Detailed Description

Action Client node for interacting with a ROS action server.

Author
Arecco Martino
Version
0.1
Date
27/02/2025

This node acts as a ROS action client that sends goals to an action server and monitors their status. It also publishes the robot's position and velocity.

Subscribed_Topics

  • /odom (nav_msgs::Odometry): Receives odometry data from the robot.

Published_Topics

  • /position_velocity (Simulation_pkg::PositionVelocity): Publishes the robot's position and velocity.

Action_Clients

  • /reaching_goal (assignment_2_2024::PlanningAction): Sends goals to the action server.
