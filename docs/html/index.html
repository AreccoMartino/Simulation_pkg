ROS Action Client and Target Service Node Documentation

Introduction

This project consists of two key components:

  • Action Client Node: A ROS node that interacts with a ROS action server, sending goals and monitoring their status.
  • Target Service Node: A ROS node that provides a service to retrieve the current target coordinates (x, y) and updates the coordinates by subscribing to a specific topic.

These nodes work together in a simulation system to handle goal coordination and tracking.

Action Client Node


This node is responsible for interacting with a ROS action server. It sends goals and monitors the action's status. The Action Client Node performs the following operations:

  • Sends goal coordinates to the action server.
  • Monitors the status of the goal, checking if it has been reached or aborted.
  • Publishes the robot's position and velocity through a custom message.

Target Service Node


The Target Service Node provides a service to return the current target coordinates and updates the target coordinates based on incoming messages. It performs the following tasks:

  • Provides the get_target service that responds with the current target coordinates (x, y).
  • Subscribes to the position_velocity topic to update the internal target coordinates.
