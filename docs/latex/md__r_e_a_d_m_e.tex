\hypertarget{md__r_e_a_d_m_e_autotoc_md9}{}\doxysection{Description of action\+\_\+client\+\_\+node}\label{md__r_e_a_d_m_e_autotoc_md9}
The {\ttfamily action\+\_\+client\+\_\+node} is responsible for interacting with an action server, sending goals, monitoring their status, and publishing the robot\textquotesingle{}s current position and velocity.\hypertarget{md__r_e_a_d_m_e_autotoc_md10}{}\doxysubsection{Key Features\+:}\label{md__r_e_a_d_m_e_autotoc_md10}

\begin{DoxyItemize}
\item {\bfseries{User Interaction}}\+: The node accepts user input to set or cancel goals.
\item {\bfseries{Action Client}}\+: Manages goals using R\+OS 2 action clients, sending targets to the robot and receiving feedback.
\item {\bfseries{Odometry Processing}}\+: Subscribes to the {\ttfamily /odom} topic to get the robot\textquotesingle{}s position and velocity.
\item {\bfseries{Publishing Position and Velocity}}\+: Publishes this data as a custom message {\ttfamily position\+\_\+velocity}.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md11}{}\doxysubsection{Code Overview\+:}\label{md__r_e_a_d_m_e_autotoc_md11}

\begin{DoxyItemize}
\item {\bfseries{Action Client Initialization}}\+: The action client is set up to communicate with the {\ttfamily /reaching\+\_\+goal} action server.
\item {\bfseries{Odometry Callback}}\+: The {\ttfamily odom\+Callback} function processes odometry messages and updates the {\ttfamily position\+\_\+velocity} topic with the robot\textquotesingle{}s current state.
\item {\bfseries{Goal Monitoring Thread}}\+: A separate thread checks the status of the goal, allowing users to know when the robot reaches the target or if the goal is aborted.
\item {\bfseries{User Commands}}\+: The node accepts user commands\+:
\begin{DoxyItemize}
\item {\ttfamily set} to set a goal.
\item {\ttfamily cancel} to cancel an ongoing task.
\end{DoxyItemize}
