Detailed Description

Target Service Node for handling target coordinates.

Author
Arecco Martino
Version
0.1
Date
27/02/2025

This node provides a ROS service that returns the current target coordinates (x, y) when requested. It also subscribes to a topic that receives updated target coordinates and updates its internal state.

Subscribed_Topics

  • position_velocity (Simulation_pkg::PositionVelocity): Receives updated target position and velocity.

Published_Topics

  • None.

Services

  • get_target (Simulation_pkg::TargetService): A service that returns the current target coordinates.
