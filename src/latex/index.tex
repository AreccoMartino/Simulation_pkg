\hypertarget{index_intro}{}\doxysection{Introduction}\label{index_intro}
This project consists of two key components\+:
\begin{DoxyItemize}
\item {\bfseries{Action Client Node}}\+: A R\+OS node that interacts with a R\+OS action server, sending goals and monitoring their status.
\item {\bfseries{Target Service Node}}\+: A R\+OS node that provides a service to retrieve the current target coordinates (x, y) and updates the coordinates by subscribing to a specific topic.
\end{DoxyItemize}

These nodes work together in a simulation system to handle goal coordination and tracking.

\hypertarget{index_action_client_node}{}\doxysection{Action Client Node}\label{index_action_client_node}
~\newline
 This node is responsible for interacting with a R\+OS action server. It sends goals and monitors the action\textquotesingle{}s status. The Action Client Node performs the following operations\+:
\begin{DoxyItemize}
\item Sends goal coordinates to the action server.
\item Monitors the status of the goal, checking if it has been reached or aborted.
\item Publishes the robot\textquotesingle{}s position and velocity through a custom message.

\hypertarget{index_target_service_node}{}\doxysection{Target Service Node}\label{index_target_service_node}
~\newline
 The Target Service Node provides a service to return the current target coordinates and updates the target coordinates based on incoming messages. It performs the following tasks\+:
\begin{DoxyItemize}
\item Provides the {\ttfamily get\+\_\+target} service that responds with the current target coordinates (x, y).
\item Subscribes to the {\ttfamily position\+\_\+velocity} topic to update the internal target coordinates.
